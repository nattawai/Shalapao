# นโยบายความเป็นส่วนตัว (Privacy Policy)

**Shalapao** · ปรับปรุงล่าสุด: _(ใส่วันที่ตอนเผยแพร่)_

## 1. ใครเก็บข้อมูล

Shalapao เป็นบริการที่พัฒนาและดูแลโดย **ไว (Shalam Corporation)** ในฐานะผู้ควบคุมข้อมูลส่วนบุคคล

ติดต่อเรื่องข้อมูลส่วนบุคคล: **contact@waivern.org**

## 2. เก็บข้อมูลอะไรบ้าง

**ข้อมูลที่ได้จาก LINE เมื่อคุณเข้าใช้งาน**

| ข้อมูล | ใช้ทำอะไร |
|---|---|
| LINE User ID | ระบุว่าข้อมูลกระเป๋าและรายการใดเป็นของคุณ |
| ชื่อที่แสดงใน LINE | แสดงในแอป |

เราไม่ได้รับและไม่ได้เก็บ อีเมล เบอร์โทร รูปโปรไฟล์ หรือรายชื่อเพื่อนของคุณจาก LINE

**ข้อมูลที่คุณกรอกเอง**

ชื่อกระเป๋า · จำนวนเงิน · วันที่ · บันทึกย่อ · หมวดค่าใช้จ่าย · ยอดที่คุณกรอกตอนกระทบยอด

**เราไม่เชื่อมต่อกับธนาคารใด ๆ** ไม่ดึงยอดบัญชี ไม่เห็นรายการเดินบัญชีของคุณ ข้อมูลการเงินทั้งหมดในระบบคือสิ่งที่คุณพิมพ์เข้ามาเอง

**ข้อมูลที่เราไม่เก็บ**

เลขบัญชีธนาคาร · เลขบัตรเครดิต · เลขบัตรประชาชน · ตำแหน่งที่ตั้ง · พฤติกรรมการใช้งานเพื่อโฆษณา

ไม่มีระบบติดตามหรือวิเคราะห์พฤติกรรมของบุคคลที่สาม

## 3. ใช้ข้อมูลทำอะไร และด้วยฐานทางกฎหมายใด

| วัตถุประสงค์ | ฐานทางกฎหมาย |
|---|---|
| ให้บริการตามที่คุณขอใช้ (เก็บและแสดงข้อมูลกระเป๋าเงินของคุณ) | ความจำเป็นเพื่อปฏิบัติตามสัญญา |
| ยืนยันตัวตนผ่าน LINE เพื่อไม่ให้คนอื่นเห็นข้อมูลของคุณ | ความจำเป็นเพื่อปฏิบัติตามสัญญา |
| แก้ไขข้อขัดข้องและปรับปรุงความปลอดภัย | ประโยชน์โดยชอบด้วยกฎหมาย |

**เราไม่ขายข้อมูลของคุณ ไม่ใช้เพื่อโฆษณา และไม่แบ่งปันให้บุคคลที่สามเพื่อการตลาด**

## 4. ใครเห็นข้อมูลของคุณบ้าง

| ผู้ให้บริการ | เห็นอะไร | ทำไม |
|---|---|---|
| **LINE** | ID token ตอนเราขอให้ยืนยันตัวตน | LINE เป็นผู้ออก token และมีข้อมูลนี้อยู่แล้ว |
| **Cloudflare** | ข้อมูลทั้งหมดที่เก็บในฐานข้อมูล | เป็นผู้ให้บริการประมวลผลและฐานข้อมูล |

ผู้ใช้คนอื่นไม่เห็นข้อมูลของคุณ ยกเว้นกระเป๋าที่คุณเลือกแบ่งปันเอง (ฟีเจอร์นี้ยังไม่เปิดใช้งาน)

## 5. ข้อมูลอยู่ที่ไหน

ข้อมูลเก็บบนโครงสร้างพื้นฐานของ **Cloudflare** ซึ่งเป็นผู้ให้บริการในต่างประเทศ และข้อมูลอาจถูกจัดเก็บหรือประมวลผลนอกราชอาณาจักรไทย

การใช้บริการนี้ถือว่าคุณรับทราบการโอนข้อมูลไปต่างประเทศดังกล่าว

## 6. เก็บไว้นานแค่ไหน

เก็บไว้ตราบเท่าที่คุณยังใช้บริการ · เมื่อคุณขอลบ เราจะลบข้อมูลทั้งหมดของคุณออกจากฐานข้อมูล

หมายเหตุ: ฐานข้อมูลมีระบบย้อนเวลาอัตโนมัติของผู้ให้บริการที่เก็บประวัติการเปลี่ยนแปลงไว้ **30 วัน** ข้อมูลที่ลบแล้วอาจยังอยู่ในระบบสำรองดังกล่าวจนครบกำหนด แล้วจะหายไปเอง

## 7. สิทธิของคุณ

ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 คุณมีสิทธิ

- ขอเข้าถึงและขอสำเนาข้อมูลของคุณ
- ขอแก้ไขข้อมูลที่ไม่ถูกต้อง
- ขอลบข้อมูลของคุณ
- ขอให้ระงับการใช้ข้อมูล
- คัดค้านการประมวลผล
- ขอให้โอนข้อมูลไปยังผู้ควบคุมรายอื่น
- ถอนความยินยอม
- ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล

ติดต่อใช้สิทธิที่ **contact@waivern.org** · เราจะดำเนินการภายใน **30 วัน**

## 8. ความปลอดภัย

- เข้าใช้งานได้เฉพาะผ่านการยืนยันตัวตนกับ LINE ทุกครั้ง — ระบบไม่รับตัวตนที่ส่งมาจากฝั่งผู้ใช้โดยตรง

ไม่มีระบบใดปลอดภัยสมบูรณ์ เราจึงไม่รับประกันว่าจะไม่มีเหตุการณ์ใดเกิดขึ้นได้เลย
